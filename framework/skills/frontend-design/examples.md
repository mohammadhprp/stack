# Frontend Design Examples

## Landing page for a telescope maker

User: "Design a landing page for our new observatory-grade telescope."

Good agent behavior:

- Pin the subject before designing: the telescope, its audience (serious amateur astronomers), and the page's single job (making the telescope's engineering credible).
- Ground the direction in the subject's world: starlight, optics, all-night observing sessions — not the generic SaaS hero.
- Sketch a token system first: a charcoal-sky palette with a silver-lens accent, a display face with fine hairlines for optical schematics, and a signature element such as a real diagram of the telescope's optical path.
- Review the plan against the brief and call out anything that reads like a default (e.g., "a big number with a small label and gradient accent") before revising it.
- Build with real copy: specifications, field notes, observing-session time-lapses, not lorem ipsum.

## Reshaping an existing dashboard

User: "Our analytics dashboard feels generic. Give it an identity without breaking the workflows."

Good agent behavior:

- Treat this as reshaping existing UI, not a greenfield build: audit the current structure first and keep every workflow intact.
- Choose one memorable signature — such as a hand-drawn annotation layer over charts — and keep everything else quiet and disciplined.
- Replace the template palette with a deliberate one drawn from the product's subject, and cut decoration that does not serve the data.
- Verify the result is responsive down to mobile, keeps visible keyboard focus, and respects reduced motion.

## Avoiding the AI-default look

User: "Make a portfolio for an independent film editor. Previous drafts all looked the same."

Good agent behavior:

- Recognize the default clusters (cream background + serif + terracotta, near-black + acid accent, broadsheet with hairline rules) and avoid spending creative freedom on them.
- Ground the direction in film editing: cutting-room tools, contact sheets, splice marks, timecodes.
- Propose a type pairing and layout concept the editor wouldn't get from any template, justified against the brief.
- Take one real aesthetic risk the brief supports, and cut every accessory that doesn't serve it.

## Applying the brief's explicit direction

User: "I specifically want the near-black background with a bright accent. That's the brand."

Good agent behavior:

- Follow the brief exactly — the brief's own words always win, including when it asks for one of the default looks.
- Execute the chosen direction with precision: a disciplined type scale, exact spacing, and an accent used sparingly.
- Spend the remaining freedom on subject-specific details rather than fighting the brief.

# Examples

- “Untangle this Laravel backend.” Ask about optional comment and test cleanup, map the main workflows, and record coupling before refactoring.
- “Untangle checkout.” Trace the checkout routes, validation, authorization, order persistence and queued side effects; preserve their behavior and verify relevant tests.
- “Untangle our order jobs and clean up comments, but leave tests alone.” Focus on the jobs and their dependencies, preserve the test suite, and check retry and transaction behavior.

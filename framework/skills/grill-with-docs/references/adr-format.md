# ADR format

Scan the applicable `docs/adr/` directory for the highest number and increment by one. Use `0001-slug.md` for the first record. Capture one decision per file.

```markdown
# Short title of the decision

One to three sentences: what was the context, what did we decide, and why?
```

Add status, considered options, or consequences only when they provide useful context. Decisions that may justify an ADR include costly technology commitments, domain ownership boundaries, integration contracts, and deliberate departures from what a future reader would otherwise assume. Each still needs to pass all three gates.
